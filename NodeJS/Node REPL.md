## Demonstrate Node REPL (Read-Eval-Print Loop)

- ### It stands for Read-Eval-Print Loop or Read,Evaluate, Print and Loop. It’s an interactive programming environment that allows you to execute JavaScript code one statement at a time.

#### Just open your terminal and type `node`. Try the following:

```bash
> 10 + 5
15
> const msg = "Hello";
> msg.toUpperCase()
'HELLO'
```

Exit by typing `.exit` or pressing `Ctrl + C` twice.
